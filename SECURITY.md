# Security Policy — UNICOM AI

## Supported Versions
Only the latest release branch and tags receive security patches.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability
Please do not file public GitHub issues for security vulnerabilities.
Email security disclosures to: `security@unicom.ai`.
We will acknowledge receipt within 24 hours and provide coordinated disclosure updates.
